# Reel music beds

Royalty-free background music for football Reels, embedded into the MP4 by
`lib/social/video-renderer.js` (picked per story by `lib/social/reel-music.js`).

**Source / license:** Mixkit (https://mixkit.co/free-stock-music/). Mixkit Free
License — free for commercial and non-commercial use in videos (including
monetized social media), **no attribution required**. You may NOT redistribute
the tracks as standalone files or use them where the music is the primary value;
as a background bed inside our own video, use is permitted.

These are deliberately NOT Instagram's native "trending" audio: the Graph API
cannot attach IG library music to API-published Reels, and embedding a real chart
song would be copyright infringement (Content-ID mute/strike). See
`.claude/agents/ig-fifa-sme.md` → Reels section.

To add more beds: drop any commercial-use `.mp3` here; the picker rotates over
all files deterministically per story.
